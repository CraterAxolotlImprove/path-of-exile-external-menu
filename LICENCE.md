## 🧩 About

**Path of Exile desktop helper** is a curated list of Path of Exile open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot filter preview, map overlay
- **Quality-of-Life Helpers** — stash organizer, trade helper notes, config manager
- **Research Notes** — build layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Loot Filter Overlay — preview and toggle filters in-game
- Map Overlay — display minimap and boss locations
- Stash Organizer — auto-sort items by category
- Trade Helper Notes — quick reference for trade interactions

### 🎨 Interface & Info
- Build Planner — track skill tree and gear goals
- Item Info Overlay — show detailed stats on hover
- Custom HUD — rearrange UI elements for clarity
- Chat Commands — quick access to common commands

### 🏋️ Practice Layout
- DPS Meter — monitor damage output in real time
- Timer Overlay — track map clear times
- Notes Manager — save important game notes
